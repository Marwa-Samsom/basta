# جلستا التدريب المسجّلتان

> مخرَج في المرحلة 12. **التسجيل يقوم به صاحب المشروع** (شاشة وصوت) على نسخة مشغّلة؛ هذا جدولهما ومادّتهما.
> التجهيز قبل كل جلسة: `npm run demo:seed -w @basta/api` — متجر عرض بأربعة منتجات بصور.

## الجلسة 1 — البائعون (60 دقيقة)

| الدقيقة | الموضوع | الشاشة |
|---|---|---|
| 0–5 | ما هي بسطة، وكيف يصل مالك | الرئيسية |
| 5–15 | التسجيل والوثائق والحساب البنكي | `/vendor/register` |
| 15–30 | منتج بمتغيّرات وصور، والمراجعة، والاستيراد الجماعي | `/vendor/products` |
| 30–35 | المخزون: الموجود والمحجوز والمتاح | `/vendor/inventory` |
| 35–45 | طلب كامل: قبول ← تجهيز ← بوليصة ← شحن ← تسليم | `/vendor/orders` |
| 45–50 | الإرجاع والنزاع | `/vendor/orders`، `/vendor/disputes` |
| 50–58 | المحفظة، وموعد التحرير، والسحب، وكشف الحساب | `/vendor/finance` |
| 58–60 | أسئلة | — |

المادّة: [دليل البائع](دليل-البائع.md).

## الجلسة 2 — الإدارة (60 دقيقة)

| الدقيقة | الموضوع | الشاشة |
|---|---|---|
| 0–5 | الدخول بالتحقق الثنائي | `/login` |
| 5–10 | اللوحة: الطوابير، والتنبيه الأحمر وماذا نفعل عنده | `/admin` |
| 10–20 | مراجعة بائع ووثائقه، ومراجعة منتجات | `/admin/vendors`، `/admin/products` |
| 20–30 | الطلبات، والإلغاء قبل الشحن، والمرتجعات، والنزاعات | `/admin/orders`، `/admin/returns`، `/admin/disputes` |
| 30–40 | السحوبات، والعمولات، وأسعار الصرف | `/admin/payouts`، `/admin/commissions`، `/admin/currencies` |
| 40–48 | الكوبونات، والبانرات، والمميّز، والصفحات، وقوالب الإشعارات | `/admin/coupons`، `/admin/storefront`، `/admin/notifications` |
| 48–55 | المستخدمون والصلاحيات، وسجل التدقيق، والتقارير وتصديرها | `/admin/users`، `/admin/audit`، `/admin/reports` |
| 55–60 | خطة التراجع: من يقرّر ومتى | [LAUNCH-AND-ROLLBACK.md](../04-operations/LAUNCH-AND-ROLLBACK.md) |

المادّة: [دليل الإدارة](دليل-الإدارة.md) و [دليل التشغيل](../04-operations/ADMIN-RUNBOOK.md).
