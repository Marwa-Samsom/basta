# التشغيل المحلي — المشروع بلا استضافة

> قرار صاحب المشروع: **لا استضافة، كل شيء محلي.** هذه الوثيقة تصف البيئة
> الفعلية وكيف تقوم من الصفر، وما الذي تغيّر في بوابة المرحلة 03 نتيجة القرار.

## قاعدة البيانات — PostgreSQL محمول

Docker غير متاح على جهاز التطوير: لا صلاحيات مدير، و WSL2 غير مثبَّت.
البديل المعتمد نسخة محمولة في `.localdb/` تعمل بلا تثبيت وبلا صلاحيات.

```bash
# تشغيل الخادم — يلزم بعد كل إقلاع للجهاز
.localdb/pgsql/bin/pg_ctl.exe -D .localdb/data \
  -o "-p 5432 -c listen_addresses=localhost" -l .localdb/pg.log start

# إيقافه
.localdb/pgsql/bin/pg_ctl.exe -D .localdb/data stop
```

`.localdb/` متجاهَل في git — القاعدة تُعاد بناؤها من المهاجرات والبذور، ولا تُنقل.

## الأوامر اليومية

| الأمر | ماذا يفعل |
|-------|-----------|
| `npm run verify` | **يهدم البيئة ويعيد بناءها ويفحصها كاملة** — عشر خطوات |
| `npm run verify:quick` | الفحوص بلا هدم قاعدة البيانات — أثناء العمل |
| `npm test -w @basta/api` | الاختبارات وحدها |
| `npm run db:migrate -w @basta/api` | مهاجرة جديدة |
| `npm run db:seed -w @basta/api` | إعادة البذور |
| `npm run db:backup` | نسخة احتياطية |
| `npm run db:verify-restore` | **يستعيدها على قاعدة نظيفة ويتحقّق أن الحرّاس نجت** |
| `npm run dev:api` · `npm run dev:web` | خادم التطوير |

## ما تغيّر في بوابة المرحلة 03

البنود التي تفترض مزوّد استضافة لم تُشطب — **تُرجمت**. الهدف من كل بند بقي،
وتغيّرت صيغة إثباته:

| الهدف الأصلي | صيغته المحلية | الإثبات |
|--------------|----------------|---------|
| نشر آلي بلا تدخل يدوي | إعادة بناء البيئة من الصفر بأمر واحد | `npm run verify` — عشر خطوات |
| تراجع مجرَّب عن نشرة فاشلة | استعادة مجرَّبة من نسخة احتياطية | `npm run db:verify-restore` |
| تنبيه Sentry لخطأ مصطنع | سجل أخطاء دائم بمعرّف طلب | `logs/errors.jsonl` + اختبار |

**لماذا هذه ترجمة لا تنازل.** الغاية من النشر الآلي ليست وجود خادم بعيد، بل
أن يكون قيام النظام **مملّاً ومكرَّراً** لا طقساً يدوياً يعرفه شخص واحد.
`npm run verify` يثبت ذلك بهدم القاعدة فعلياً وإعادة بنائها — وهو اختبار
أقسى من نشرة تعتمد على حالة متراكمة على خادم.

والغاية من التنبيه أن **لا يمرّ خطأ صامتاً**. السجل الدائم يحقّقها: كل خطأ
غير متوقّع سطر JSONL بمعرّف طلب يربط بلاغ المستخدم بالسبب، والأسرار محذوفة
قبل الكتابة.

## ما بقي غير منفَّذ — وسببه

**بيئة تجريبية منفصلة ونشر عن بُعد.** لا مزوّد. البنية جاهزة: `Dockerfile`
لكل تطبيق، وخطّ فحص كامل في `.github/workflows/ci.yml`. متى وُجد مزوّد صار
التوصيل **إضافة أسرار لا إعادة بناء**.

**Sentry.** الكود موصول ومعطّل ذاتياً بلا `SENTRY_DSN`. يكفي وضع المفتاح في
`.env` ليعمل، و`GET /api/v1/health/boom` يرمي خطأً مقصوداً لإثبات الوصول.
البديل مفتوح المصدر GlitchTip متوافق مع البروتوكول نفسه ويُوصَل بنفس المتغيّر.

**Redis و Meilisearch.** غير متاحين بلا Docker على ويندوز. غير مطلوبين حتى
المرحلة 07 (البحث) و08 (الطوابير)، ويُعاد النظر فيهما عندها.
