01

الملخّص التنفيذي

المطلوب ليس متجراً إلكترونياً، بل بنية سوق: عشرات البائعين المستقلين، كل واحد بمخزونه وأسعاره وشحنه ومحفظته، فوق طبقة واحدة تديرها أنت وتقتطع منها عمولتك.

الفرق الجوهري بين متجر ومنصة أسواق يظهر في ثلاث نقاط تُبنى مرة واحدة أو تُعاد كتابة النظام لاحقاً: السلة متعددة البائعين (طلب واحد للمشتري ينقسم إلى عدة طلبات فرعية لكل بائع، بشحن وحالة مستقلة)، ومحرّك العمولات (نسبة عامة، أو لكل فئة، أو تفاوضية لكل بائع)، ودورة التسوية (احتساب مستحقات البائع بعد فترة الإرجاع، وطلبات السحب، وسجل مالي قابل للتدقيق).

هذا العرض يغطي الإصدار الأول كتطبيق ويب متجاوب بتقنية PWA — قابل للتثبيت على شاشة الهاتف ويعمل كتطبيق دون المرور بمتاجر التطبيقات. تطبيقات المتاجر الأصلية مذكورة في القسم 07 كمرحلة ثانية اختيارية، وقد صُمّمت واجهات الـ API من الآن لتخدمها دون إعادة بناء.

بسطة اسم عمل مؤقت داخل هذا المستند، ويُستبدل بالهوية النهائية عند اعتماد العرض.

نطاق العمل

4 وحدات · 47 شاشة
A — واجهة المتجر
  • رئيسية بأقسام قابلة للإدارة وبنرات وحملات
  • تصفّح فئات متعدد المستويات مع تصفية أوجه (سعر، ماركة، تقييم، بائع، سمات)
  • صفحة منتج بخيارات متعددة (مقاس/لون) وصور مكبّرة وسؤال البائع
  • صفحة بائع مستقلة: منتجاته، تقييمه، سياسات شحنه وإرجاعه
  • بحث فوري بتسامح إملائي عربي واقتراحات أثناء الكتابة
  • سلة متعددة البائعين تُقسَّم تلقائياً وقت الطلب
  • إتمام شراء بخطوة واحدة، عنوان مع خريطة، ضيف أو مسجّل
  • تتبع الطلب بحالات مستقلة لكل بائع + إشعارات
  • مراجعات موثّقة بالشراء، مفضلة، مقارنة، كوبونات
B — لوحة البائع
  • تسجيل ذاتي ورفع وثائق وحالة "قيد المراجعة"
  • إدارة منتجات: إفراد، أو استيراد جماعي CSV/Excel
  • مخزون بتنبيهات نفاد وحجز عند الطلب
  • إدارة الطلبات: قبول، تجهيز، بوليصة شحن، تسليم
  • مناطق وأسعار شحن خاصة بالبائع
  • محفظة: رصيد معلّق، رصيد متاح، طلب سحب
  • تقارير مبيعات وأفضل المنتجات وقابلية التصدير
  • ملف المتجر: شعار، غلاف، وصف، سياسات
  • مراسلة العملاء وإدارة النزاعات
C — لوحة الإدارة
  • مراجعة البائعين والموافقة والتعليق والحظر
  • شجرة الفئات والسمات ومواصفات كل فئة
  • محرّك العمولات: عام / لكل فئة / لكل بائع
  • دورة التسوية وموافقة طلبات السحب وسجل مالي
  • إدارة النزاعات والمرتجعات واسترداد المبالغ
  • كوبونات وحملات ترويجية ومنتجات مميّزة
  • إدارة صفحات المحتوى والبانرات والقوائم
  • مستخدمو الإدارة والصلاحيات وسجل تدقيق كامل
  • لوحة مؤشرات: مبيعات، عمولات، بائعون، تحويل
D — الأنظمة الخلفية
  • تقسيم الطلب تلقائياً حسب البائع مع رقم أب ورقم فرعي
  • احتساب الضريبة (VAT) على مستوى المنطقة
  • عربي/إنجليزي كاملان مع RTL و LTR ومحتوى مترجَم
  • عملات متعددة مع سعر صرف قابل للتحديث
  • طبقة دفع مجرّدة (Adapter) تُوصَّل بأي بوابة لاحقاً
  • إشعارات: بريد + رسائل نصية/واتساب + Push للمتصفح
  • SEO تقني: Schema.org، sitemap ديناميكي، صفحات مفهرسة لكل بائع
  • نسخ احتياطي يومي واستعادة مجرَّبة

الافتراضات والاستثناءات

  • 01محتوى المنتجات (الصور، الأوصاف، الأسعار) وبيانات البائعين مسؤولية العميل. يشمل العرض إدخال 20 منتجاً نموذجياً لأغراض الاختبار فقط.
  • 02تكاليف الاستضافة والنطاق والشهادات وتراخيص الخدمات الخارجية خارج السعر، وتُقدَّر بـ 90 – 190 دولاراً شهرياً في مرحلة الإطلاق حسب حجم الزيارات.
  • 03تكامل بوابة دفع واحدة مشمول. فتح حساب التاجر لدى البوابة، والموافقات، والرسوم البنكية والعمولات — كلها مسؤولية العميل.
  • 04جولتان من التعديلات مشمولتان على كل مخرج تصميمي. التعديلات بعدهما، أو بعد الاعتماد الرسمي، تُعامل كطلب تغيير.
  • 05أي إضافة خارج النطاق المكتوب في القسم 02 تمرّ عبر طلب تغيير موثّق بأثره على المدة والكلفة، وتُسعَّر بـ 30 دولاراً للساعة.
  • 06يلتزم العميل بمراجعة المخرجات واعتمادها خلال 3 أيام عمل. التأخر في الاعتماد يزيح الجدول الزمني بالمدة نفسها.
  • 07الترجمة عربي/إنجليزي مشمولة كبنية تقنية؛ نصوص المحتوى التسويقي بالإنجليزية يوفّرها العميل.
  • 08الكود المصدري كاملاً ملك العميل ويُسلَّم على مستودع خاص عند سداد الدفعة الأخيرة، مع وثائق النشر والمعمارية.
  • 09لا يشمل العرض: تصميم الهوية البصرية والشعار، إنتاج الصور والفيديو، إدارة الحملات الإعلانية، أو التسجيل الضريبي والقانوني للمنصة.
